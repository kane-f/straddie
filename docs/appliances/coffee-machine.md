# Coffee Machine

## What It Is

A Breville pod coffee machine.

## Where It Is

## Quick Start

!!! tip "Pods"
    It takes standard **Nescafé-compatible pods** — not Nespresso pods.
    If you're bringing your own, buy the Nescafé-compatible kind.
