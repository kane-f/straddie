# Oven

## What It Is

A NEFF oven with **pyrolytic self-cleaning** — believed to be from the
N70 range, though the exact model hasn't been confirmed.

## Where It Is

Kitchen.

## Quick Start

Normal baking and roasting needs no special steps. The pyrolytic
self-clean cycle is there if you want to use it during your stay, but
it needs a couple of things done first — see below.

## Common Tasks

**Before running the pyrolytic (self-clean) cycle:**

1. Clean the oven glass/door glass by hand first — the pyrolytic cycle
   doesn't clean the glass itself.
2. Remove the tray guides/rack guides from the sides of the oven.
3. Start the cycle.

!!! warning "Don't skip the prep steps"
    Running the self-clean cycle with the rack guides still in means
    they get baked at pyrolytic temperatures, which isn't good for them.
    Take them out first.

## Tips

The self-clean cycle runs hot and takes a while — it's a good one to
start before heading out for the day rather than waiting around for it.
