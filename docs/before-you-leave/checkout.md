## Checkout Checklist

- [ ] General cleaning
- [ ] Dishes / dishwasher
- [ ] Fridges / freezers
- [ ] Rubbish taken out (see [Bins](#bins) below)
- [ ] Linen and towels
- [ ] Outdoor areas tidy
- [ ] BBQ cleaned
- [ ] Lights off
- [ ] Air conditioning off
- [ ] Doors and windows locked
- [ ] Keys returned
- [ ] Security set
